# Módulos del Proyecto — Guía de Directorios

Este archivo resume el propósito de cada carpeta raíz creada en la Fase 1:

- `watch-app/`: Proyecto de la aplicación para smartwatch con Wear OS.
- `windows-app/`: Aplicación de escritorio para Windows (64 bits) encargada de recibir comandos validados y ejecutar las acciones permitidas.
- `ai-module/`: Pipeline de extracción de características, entrenamiento y reconocimiento local de gestos con umbral de confianza.
- `protocol/`: Especificación del protocolo de comunicación, esquemas de validación y lista blanca de comandos permitidos.
- `poc/`: Scripts y prototipos experimentales de la Fase 2 (pruebas de sensores, comparativa Bluetooth vs. Wi-Fi y evaluación de IA local).
